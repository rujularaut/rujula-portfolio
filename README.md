# Rujula Raut Portfolio

A personal portfolio website built with a **Digital Field Notebook** theme.  
It showcases my projects, skills, milestones, and learning journey through a clean, notebook-inspired interface.

## Live Demo
```txt
https://rujula-portfolio.rujularaut.workers.dev
```

## Tech Stack
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Features
- Interactive project journal
- Page-style project navigation
- Smooth animations
-Responsive design
- Skills and milestones sections
- Contact links

## Projects Highlighted
- KisanAwaaz
- ReLink
- MediBook
- CogniCare
- Cloudburst Prediction System
- API Test Automation Framework

## Development Note
The initial UI structure was generated with Lovable AI and then customized with my own content, project details, styling refinements, interactions, and deployment setup.

## Run Locally
```
npm install
npm run dev
```
## Build
```
npm run build
```
